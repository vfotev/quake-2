What is this mod?

This mod is supposed to be a copy of the Call of Duty Zombies mode, but I haven’t quite gotten around to finishing everything. What has been done so far is that enemies will spawn in waves, as well as drop loot when they die. Below will be instructions on how to play the mod.

New Controls Added:
● Pressing the “M” key will make the enemies start to spawn in waves
● Pressing F1 will display a menu that will show what the mod is and how many
  waves deep the player is in

How to Install Quake 2 Zombies:
● Locate the folder called Zombies in the repo
● Download the file
● Next, go into your Steam library
● Right-click on Quake 2
● Click on Browse Local Files
● Next, move the Zombies folder that you just downloaded into the root of the
  Game files
● Launch Quake 2 Classic
● Press the “~” key to open the console
● Type “game zombies”(This will launch the mod)
● Now type “map q2dm1”(This will load into a map)
● Once loaded in, open the console again
● Type “bind “m” spawn_wave” (This will bind your M key to start the Zombies mod,
  this is something that will only have to be done once)
● Now enemies will spawn in waves until the player dies
● ENJOY!
